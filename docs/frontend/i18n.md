# Ngôn ngữ giao diện

## Cài đặt

- Settings → **Chung** → **Ngôn ngữ / Language**: English (mặc định, đứng đầu danh sách) hoặc Tiếng Việt. Giá trị đã lưu luôn thắng mặc định, nên người dùng cũ không bị đổi ngôn ngữ; test cần chữ Việt thì bọc `LangContext.Provider value="vi"` thay vì dựa vào mặc định. Lưu trong `Appearance.lang` (`silence.appearance.v2`); `applyAppearance` đặt `<html lang>`.
- Mỗi lúc chỉ **một** ngôn ngữ: không pha hai thứ tiếng trong chuỗi giao diện.
- Câu trả lời của agent theo ngôn ngữ **user viết**, không theo cài đặt này. Engine tự quyết (`crates/runtime/src/lang.rs::decide`) rồi ghi dòng `Reply language` trong `<turn_context>`. Tin nhắn không rõ ngôn ngữ (vd. "ok", chỉ dán log) thì giữ ngôn ngữ lượt trước. Nếu chưa có lượt nào thì dùng ngôn ngữ giao diện: Studio gửi `ui_lang` kèm `session.prompt` (protocol 0.1.19).

## Cách dùng trong code

- Chuỗi nằm trong `DICT` của `i18n.ts`. Bản `en` định nghĩa khoá (`MsgKey`), bản `vi` phải có đủ khoá: TypeScript báo lỗi nếu thiếu. `i18n.test.ts` kiểm hai bản dùng cùng `{biến}` cho mỗi khoá.
- Component: `const t = useT();` rồi `t("auto.used", { usd })`. Ngoài component: `translate(lang, key, vars)` hoặc `translator(lang)`.
- `App` nằm trên `LangContext` nên dùng `translator(appearance.lang)`; mọi component bên dưới dùng `useT()`.
- Hàm thuần trả chuỗi UI nhận tham số `t: T` (vd. `pulseLabel`, `errorCopy`, `tierBadge`, `scopeLabels`, `contextTip`, `usageRows`, `imagesFromFiles`, `editPrompt`, `authLabel`, `expiryNote`). Test truyền `translator("vi")` / `translator("en")`.
- Ngày giờ format theo khoá `locale` (`vi-VN` / `en-US`), không theo locale hệ điều hành.
- Đặt tên khoá theo vùng: `chat.*`, `meta.*`, `composer.*`, `perm.*`, `history.*`, `img.*`, `ie.*` (trình đánh dấu ảnh), `appear.*`, `src.*` / `cli.*` (nguồn model), `models.*`, `err.<CODE>.*`…

## Không dịch

- Tên sản phẩm và tên riêng: 5ilence, Auto, Plan/Agent/Debug/MultiTask/Review/Ask, Code (thẻ hub), Frontier/Strong/Small, tên model, tên nguồn, tên bảng màu (Espresso, Graphite…), Fork.
- Thuật ngữ giữ nguyên ở bản Việt (đã dùng như vậy trong copy tiếng Việt): workspace, Chat Workspace, Agents, Terminal, Output, Debug Console, Changes, Checkpoint, Apply / Reject, diff, token, context, tool, slug, API key.

## Dữ liệu lưu và chuỗi từ Engine

- Động từ bước (`Read`, `Searched`, `Running`…) và chi tiết cố định (`file`, `command`, `` `q` in file ``) lưu trong lịch sử bằng tiếng Anh; chỉ dịch lúc hiển thị (`verbText` / `detailText` / `stepText` trong `chatMeta.ts`). Động từ lạ hiện nguyên văn.
- Tiêu đề chat mặc định ("Đoạn chat mới" / "New chat", kể cả sau "Fork · ") hiện theo ngôn ngữ hiện tại (`shownTitle`); tiêu đề thật (từ prompt, AI, user) giữ nguyên.
- Lý do leo cấp của Auto (Engine, tiếng Anh cố định) đổi bằng `escalationText`. Thêm câu mới ở `agent/auto.rs` thì thêm cả mẫu trong `escalationText`.
- Còn hiện nguyên văn từ Engine (chưa dịch được ở UI): lý do rủi ro trong permission card (`risk.reasons[].title/detail`), lý do gợi ý đổi mode, `unavailable_reason` của nguồn/model, danh sách "Cách 5ilence chạy CLI" (`cli_info.safeguards`), thông báo lỗi kỹ thuật (`[error] …`) và dòng `sys`. Muốn dịch thì Engine gửi mã ổn định, UI map sang khoá.

## Đã chuyển

Toàn bộ renderer đang dùng (`apps/studio/src/renderer`):

- Khung: TitleBar (menu, nút cửa sổ), tab chat, lịch sử chat (nhóm ngày, trạng thái, đổi tên/xoá, Agent mới, Tìm kiếm…), bottom panel.
- Hội thoại: hub trống, meta lượt (Worked for, Thought, Explored, bước, checkpoint, Tool details), run pulse và tooltip, chip Auto, footer Copy / Fork, toast, thẻ gợi ý đổi mode, plan card, permission card, thẻ lỗi.
- Composer: placeholder, mô tả mode, menu model (cả Auto), menu Files, báo cáo Context Usage, hint chỉ đọc / ảnh / không đọc được ảnh, nút công cụ.
- Diff: DiffCard, DiffPane (tab, Apply/Reject, placeholder), code block và bảng diff, khối SVG (`VisualBlock`), Markdown (ảnh bị chặn, link file).
- Ảnh: lightbox, thanh thao tác trên ảnh (`ImageFrame`), ảnh workspace, trình đánh dấu ảnh (`ImageEditor`) và prompt điền sẵn.
- Settings: Chung (Ngôn ngữ, nguồn mặc định, đặt lại), Giao diện (Chủ đề, bảng màu, mật độ, màu nhấn, hình nền), Quyền (chế độ, quyền đã nhớ), Model (Nguồn + chi tiết Claude CLI, Auto, danh sách Model và form thêm model), Phím tắt, Giới thiệu, ô tìm kiếm.
- Log tab Output do Studio ghi (`[warn]` / `[error]` + câu), hộp xác nhận khôi phục checkpoint, prompt điền sẵn (Review, Sửa plan, Duyệt plan).

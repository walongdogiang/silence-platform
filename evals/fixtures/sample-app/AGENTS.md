# sample-app

Nội bộ fixture cho eval v0. Python 3.11, không framework.

- `src/calc.py` — số học
- `src/user.py` — user store in-memory
- `src/api.py` — HTTP-ish handlers (dict in, dict out)
- `src/util.py` — path/string helpers
- `src/stats.py` — thống kê list
- `tests/` — chạy bằng `python -m tests.runner`

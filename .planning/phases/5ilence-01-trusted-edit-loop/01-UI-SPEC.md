## Copywriting Contract

Product UI speaks Vietnamese for user-facing chrome; keep existing English Diff verbs **Apply** / **Reject** (already shipped). Agent system prompts stay English (out of UI-SPEC).

| Element | Copy |
|---------|------|
| Primary CTA (no workspace) | **Mở workspace** — empty-hub + File menu; opens folder then enables prompt path |
| Primary CTA (permission) | **Cho phép** — answers Ask; Engine remains source of truth |
| Primary CTA (diff) | **Apply** — commits staged file contents via `diff.apply`; only then may disk match `after` |
| Secondary (permission) | **Từ chối** — denies tool; no remember write |
| Secondary (diff) | **Reject** — discards staged proposal via Engine reject path; disk must remain `before` |
| Remember control | Checkbox label: **Nhớ cho workspace này** — visible on permission banner; default **checked** when Allow; unchecked Deny never persists; Engine persists workspace allowlist (not `localStorage` as sole gate) |
| Permission heading | **Cho phép {tool}?** — `{tool}` = protocol tool name (`edit`, `write`, `shell`, …) |
| Diff banner heading | **Diff {path}** — `{path}` workspace-relative; truncate with ellipsis mid-path if overflow |
| Empty DiffPane list | **Chưa có thay đổi** |
| Empty Diff editor | **Chọn file hoặc chờ agent tạo diff** |
| Empty chat (no session) | Heading **Bắt đầu với workspace** / body **Mở folder dự án để chat với agent. Plan trước khi sửa file.** |
| Empty chat (has session) | Heading **Bạn muốn bắt đầu thế nào?** / body references ready workspace (existing empty-hub) |
| Empty history | **Mở workspace để xem lịch sử.** / **Chưa có đoạn chat.** (existing; no redesign) |
| Error — Apply failed | **Không áp dụng được thay đổi.** + next step: **Thử Apply lại hoặc Reject rồi để agent đề xuất lại.** |
| Error — Permission RPC failed | **Không gửi được quyết định quyền.** + next step: **Cho phép hoặc Từ chối lại; nếu vẫn lỗi, mở lại workspace.** |
| Error — Prompt/session missing | Send stays disabled until session exists (existing composer); no silent fake success |
| Destructive confirmation | Checkpoint **Restore** only (existing `window.confirm` copy). **Reject** does **not** use a confirm dialog (discard staged proposal). Plan Approve UI deferred to Phase 2 — do not expand copy here |

Composer placeholder (unchanged): `Plan, Build, / for skills, @ for context`.

Copy Message toast (unchanged): `Message copied to clipboard` — must never include tool/diff/permission payloads (`docs/frontend/chat.md`).

## Phase Surfaces (interaction contract)

### A. Permission Ask banner (`ChatPane` `.banner.warn`)

| Rule | Contract |
|------|----------|
| When | `SessionEvent::Permission` while session default mode is Ask |
| Content | Heading + `JSON.stringify(input)` in `<pre>` + Remember checkbox + Cho phép / Từ chối |
| Loading | Disable both actions + checkbox while `session.permission` RPC in flight; no double-submit |
| Success | Banner unmounts; if Remember checked and Allow, subsequent same tool name must not re-prompt in this workspace after Engine reload of allowlist |
| Deny | Clears banner; tool does not run; no allowlist write |
| Channel | Separate from chat Copy; not part of AI message text |

### B. Diff review — banner + DiffPane (stage-then-apply)

| Rule | Contract |
|------|----------|
| Semantics | Mutating tools stage a proposal; **disk unchanged until Apply**; Reject leaves disk at `before` (LOOP-01 / RESEARCH) |
| Banner | Shown when `diff` non-null: heading + Apply + Reject |
| DiffPane visibility | Mount/show only when `diff \|\| file` (`.cursor/rules/frontend-shell.mdc`) |
| DiffPane Changes | Read-only Monaco showing `after` while pending diff; file list marks path with `M` |
| Loading | Disable Apply/Reject until RPC settles; keep banner visible on failure (show error copy) |
| Apply | `diff.apply` then clear pending UI; optional refresh open file buffer to `after` |
| Reject | Must call Engine reject/discard (not UI-only `setDiff(null)`); clear banner + pending DiffPane state |
| Multi-file queue polish | Out of scope — tracer = one pending diff at a time |
| Unified hunk IDE | Out of scope — no side-by-side redesign in Phase 1 |

### C. Chat Workspace prompt path (minimal)

| Rule | Contract |
|------|----------|
| Layout | Existing Chat Workspace: tabs + ChatPane + composer + history — **no shell redesign** |
| Boundary | Renderer only `window.silence.rpc` / events — never model/fs/shell directly |
| Session | `session.create` with `permission: "ask"`; no product YOLO control in Phase 1 UI |
| Busy | Composer send disabled while `busy`; permission/diff banners remain actionable |
| Plan card / Duyệt plan | May remain in tree but **Phase 2** owns semantics — do not expand Plan Approve UX here |
| Composer modes | Keep existing chips; Phase 1 trusted loop uses Agent prompt path; Debug/MultiTask/Ask stay UI stubs |

### Deferred UI (explicit non-goals for this contract)

- Plan Approve flow polish (Phase 2)
- MCP allowlist screens (Phase 4)
- Sub-agent summary panels (Phase 5)
- Cost / token / audit trail panels (Phase 6)
- Full Monaco diff hunk / multi-file review IDE
- shadcn / new design-system migration

| zero-one-many | Pending diffs | ✅ covered | Phase 1 tracer: zero = no banner/DiffPane-from-diff; one = single pending proposal; many-file queue UI deferred — do not invent multi-select Apply |
| long-text | Tool name/heading; JSON input; `after` buffer | ✅ covered | Heading wraps/ellipsis; JSON pre-wrap + scroll; editor handles long files; Copy excludes permission/diff payloads |
